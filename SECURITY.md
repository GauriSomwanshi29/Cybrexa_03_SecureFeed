# Security Policy

## Project Security Notes

SecuriFeed is an educational phishing detection project.

## Implemented Safety Practices

- No user data is stored
- URL analysis runs locally in browser
- No sensitive information is collected
- No external API keys are used
- Regex checks are used for suspicious URL detection

## Limitations

This project does not guarantee real-world phishing detection accuracy.
It is created for learning and awareness.
